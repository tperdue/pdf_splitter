## When To Add A Decision

- The project chooses a framework, database, package manager, deployment target, or major dependency.
- The project establishes a convention that future work should follow.
- Multiple reasonable options existed and the choice may need explanation later.

## Entry Format

Prefer short dated entries:

```text
YYYY-MM-DD - Decision: ...
Rationale: ...
Alternatives considered: ...
Consequences: ...
```
