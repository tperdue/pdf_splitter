title: Day-Zero Python Project Baseline
---

This workspace starts as a general Python project template.

Default assumptions are intentionally minimal: use a `src/` layout for packages, keep tests under `tests/`, prefer pytest, configure tools through `pyproject.toml`, and avoid choosing a framework, database, deployment target, or external service until project requirements make that choice real.
